# Smart Book Seeker: AI Agent Retrieval System
Modern library retrieval systems face significant challenges due to expanding collection scales and sparse metadata, where books are often cataloged with titles alone, substantially impairing retrieval effectiveness. To address these limitations, we propose the Smart Book Seeker AI Agent Retrieval System (SBS-AARS), a novel multi-agent collaborative architecture comprising three coordinated components. First, a User-Needs Agent clarifies ambiguous search requirements through interactive dialogue. Second, a Librarian Agent executes traditional keyword-based retrieval to obtain candidate books. Third, a User Agent acts as a domain-knowledge-equipped proxy that collaborates with the Librarian Agent through multi-turn discussions to evaluate and select optimal results, compensating for users' frequent lack of domain expertise in assessing retrieval outcomes. Experimental evaluation on 20,000 Chinese books demonstrates substantial improvements over baseline methods: our system achieves 87% hit rate and 57% precision at top-5 results, representing 28% and 90% improvements respectively over traditional keyword-based retrieval, while maintaining 55% precision and recall at top-10 results. These findings validate the effectiveness of multi-agent collaboration in overcoming metadata sparsity for library book discovery.
